# Photos

Drop photographs here (JPEG or WebP, about 2000 px on the long side keeps the page fast), then add one entry per photo to `photos` in `js/content.js`:

```js
{ src: "photos/forest-park.jpg", title: "Forest Park, St. Louis", settings: "35mm · ƒ/2 · 1/500 · ISO 100", year: "2026" }
```

`settings` and `year` are optional. The film strip on the homepage appears as soon as the list has at least one photo.
